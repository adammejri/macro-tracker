# Macro & Activity Tracker

A Python-based CLI tool for tracking daily nutrition and activity.

## Features
- Scrape nutrition data from Citygross
- Log meals and track macros
- Calculate TDEE based on activities
- View historical data

## Stack
- Python 3.11
- SQLite (raw SQL)
- Flask REST API (coming soon)
- JavaScript frontend (coming soon)

## Setup
\`\`\`bash
conda activate macro-calculator
python main.py
